# Lunar Ice Watch

A dashboard for screening and tracking lunar south pole ice candidate sites. Provides site detail views, an interactive map, traverse planning, and data upload tools for reviewing potential ice deposits.

## Features

- **Dashboard** — overview of tracked ice candidate sites
- **Site detail** — per-site data and metrics
- **Map view** — geographic visualization of candidate sites
- **Traverse planning** — route planning between sites
- **Data upload** — import new site data
- **Login** — access control for the dashboard

## Running locally

```bash
npm start
```

The server runs at `http://localhost:3000`.
